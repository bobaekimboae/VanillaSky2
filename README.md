# VanillaSky2 한국어 차량 영상 제작기

VanillaSky의 실제 차량 등록 및 영상 설정 화면을 확인한 뒤, 그 화면 흐름을 한국어로 구현한 독립 프런트엔드입니다.

## 사용 방법

1. [VanillaSky2](https://bobaekimboae.github.io/VanillaSky2/)를 Chrome 또는 Edge에서 엽니다.
2. 차량 사진 3~20장(JPG, PNG, WebP, 각 20MB 이하)을 올리고 차량명과 필요한 정보를 입력합니다.
3. 목적, 화면 비율, 템플릿, 사진 색감, 음악 분위기, 내레이션, 로고와 장면 문구를 설정합니다.
4. 미리보기에서 장면을 확인하고 WebM 동영상을 저장합니다.

사진은 브라우저에서 처리합니다. 선택한 VIN은 미국 NHTSA vPIC API로 전송해 차량 정보를 조회합니다. 일반 매물 링크의 사진 자동 수집 서버는 연결되어 있지 않습니다.

## 기능과 한계

- 사진 여러 장 업로드, 삭제와 순서 변경, 장면별 사진 교체 및 문구 편집
- 소셜/매물 목적, 9:16 및 16:9, 원본에서 확인한 영상 템플릿 선택
- 사진 색감 오버레이, 로고와 글꼴 설정
- 브라우저 캔버스 미리보기와 무음 WebM 파일 생성
- 기기에 설치된 음성을 이용한 브라우저 내레이션 미리듣기

이 독립 버전은 VanillaSky의 로그인, 결제, 서버, 생성형 AI 동영상/모션, 배경 합성, 음악 파일과 서버 음성 기능에 연결되어 있지 않습니다. 음악 카드는 설정 상태를 선택하는 UI이며 WebM 출력에는 음악이 들어가지 않습니다. 배경 옵션은 사진 색감을 바꿀 뿐 배경을 지우거나 새로 합성하지 않습니다. 결제 버튼은 실제 결제를 실행하지 않고 연결 상태 안내를 표시합니다.

## 로컬 개발 및 배포

Node.js 18 이상에서 `node preview-server.mjs`를 실행한 뒤 `http://127.0.0.1:5502`를 엽니다. `main` 브랜치에 변경사항을 반영하면 GitHub Actions가 Pages를 배포합니다.
