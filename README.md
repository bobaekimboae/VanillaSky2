# VanillaSky2 한국어 차량 영상 제작기

VanillaSky의 실제 차량 등록 및 영상 설정 화면을 확인한 뒤, 그 흐름을 참고해 한국어로 구현한 독립 프런트엔드입니다.

## 사용 방법

1. 최신 Chrome 또는 Edge에서 [VanillaSky2](https://bobaekimboae.github.io/VanillaSky2/)를 엽니다.
2. **사진 업로드**를 선택해 차량 사진 3~20장(JPG, PNG, WebP, 장당 20MB 이하)을 올립니다.
3. 차량명과 선택 정보를 적고 영상 목적, 화면 비율, 템플릿, 사진 색감, 음악 분위기, 음성, 로고와 장면 문구를 설정합니다.
4. 미리보기에서 장면을 확인한 뒤 브라우저에서 무음 WebM 영상을 저장합니다.

매물 링크 자동 수집은 아직 연결되어 있지 않습니다. VIN은 미국 NHTSA vPIC API로 전송해 기본 차량 정보를 조회합니다. 사진 파일 자체는 브라우저에서 처리하며 서비스 서버에 올리지 않습니다.

## 기능 범위

- 여러 사진 업로드, 삭제/순서 변경, 장면별 사진 교체와 문구 편집
- 차량 매물/소셜 형식, 세로 9:16 및 가로 16:9, 원본 흐름에서 확인한 템플릿 선택
- 사진 색감 오버레이, 로고와 글꼴 설정
- 브라우저 캔버스 미리보기와 무음 WebM 생성
- 브라우저에 설치된 음성으로 내레이션 미리듣기

이 버전은 VanillaSky 계정/서버, 유료 결제, 생성형 AI 모션 영상, 배경 이미지 합성, 실제 음악 파일, 다운로드 영상 내 TTS 오디오, 매물 사이트 사진 자동 수집에 연결되어 있지 않습니다. 음악은 설정 선택만 되며 출력 WebM은 무음입니다. 배경 설정은 원본 사진에 색감을 덧입힙니다. 결제 버튼은 결제를 실행하지 않고 미연결 안내를 표시합니다.

## 개발 및 배포

Node.js 18 이상에서 `node preview-server.mjs`를 실행하면 `http://127.0.0.1:5502`에서 볼 수 있습니다. `main` 브랜치 push 시 GitHub Actions가 Pages에 배포합니다.
