# VanillaSky2 한국어 차량 영상 제작기

원본 VanillaSky의 공개된 차량 등록 및 편집 흐름을 참고해 독립적으로 구현한 한국어 웹 앱입니다. 여러 장의 차량 사진을 이어 붙여 세로형 숏폼(9:16) 또는 가로형 매물 영상(16:9)을 만들고 WebM 파일로 저장할 수 있습니다.

## 사용 방법

1. 최신 Chrome 또는 Edge에서 [웹 앱](https://bobaekimboae.github.io/VanillaSky2/)을 엽니다.
2. 차량 사진 3~20장과 차량 정보를 입력합니다.
3. 형식, 비율, 영상 스타일, 배경 색감, 음악, 로고와 장면 문구를 설정합니다.
4. 미리보기에서 장면을 확인하고 **영상 파일 만들기**를 눌러 WebM을 저장합니다.

사진과 영상은 브라우저에서 처리합니다. 별도 서버로 사진을 업로드하거나 저장하지 않습니다.

## 기능 범위

- 사진 다중 업로드, 순서 변경, 삭제, 장면 사진 교체
- 차량 매물/소셜 숏폼 형식, 세로 9:16 및 가로 16:9
- 장면 스타일, 사진 색감, 음악 분위기, 자막과 판매점 로고 설정
- 캔버스 미리보기, 브라우저 녹화 및 WebM 다운로드
- 브라우저의 한국어 음성 읽기 미리듣기

사진 분위기 설정은 색상 오버레이입니다. AI 배경 합성이나 이미지 생성은 연결되어 있지 않습니다. 외부 매물 사이트 URL 자동 수집, 생성형 AI 영상, 서버 기반 AI 음성, 결제 및 계정 기능도 연결하지 않았습니다. 음성 읽기는 미리듣기 전용이며 다운로드 파일에는 단순 합성 음향만 포함됩니다.

## 개발 및 배포

`npm start`로 미리보기 서버를 실행할 수 있습니다. `main` 브랜치에 push하면 `.github/workflows/pages.yml`이 GitHub Pages에 배포합니다.
